# Frontend - PRIVATE DUO CHAT

Ye PRIVATE DUO CHAT ka alag frontend folder hai.

## Files:
- `index.html` - Landing page
- `login.html` - Login screen
- `register.html` - Registration screen
- `dashboard.html` - Rooms dashboard (create/join rooms)
- `chat.html` - Two-person private chat UI
- `css/` - Styling sheets (`main.css`, `auth.css`, `chat.css`)
- `js/` - Logic scripts (`app.js`, `auth.js`, `dashboard.js`, `chat.js`)

## Run Karne ke 2 Tareeqe:
1. **Backend ke sath (Recommended):** Backend start karein (`cd backend && npm start`), automatically `http://localhost:3000` par frontend live ho jayega.
2. **Standalone Frontend Server:** Aap is folder ko VS Code Live Server ya kisi bhi static server se bhi alag se run kar sakte hain.
